# Sales Analysis Project 📊

## Overview
This project analyzes sales data to provide business insights using Python and SQL.

## Tools Used
- Python (Pandas, Matplotlib)
- SQL
- GitHub

## Dataset
`sales_data.csv` contains 12 sales transactions with:
- Date, Product, Category, Quantity, Price, Region, Salesperson

## Key Analysis
1. Total Sales Calculation
2. Sales by Category (Technology vs Furniture)
3. Sales by Region (North, South, East, West)
4. Top Performing Products

## How to Run
pip install pandas matplotlib
python analysis.py

## Insights
- Technology category generates the highest revenue
- North region has strong performance
- Monitor and Laptop are top products
